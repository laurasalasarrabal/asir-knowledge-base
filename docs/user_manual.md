
# Manual de usuario

## 1. Introducción

Este manual describe cómo utilizar ASIR Knowledge Base
para consultar, gestionar y actualizar la documentación
técnica del proyecto.

## 2. Acceso a la documentación

Podemos consultar la documentación desde GitBook:

https://asir-knowledge-base.gitbook.io/asir-knowledge-base-docs/

## 3. Consulta de información

Utilizamos el menú de navegación para acceder a:

- Presentación del proyecto.
- Arquitectura del sistema.
- Guía de despliegue.
- Manual de usuario.

## 4. Actualización de la documentación

1. Accedemos al repositorio de GitHub.
2. Entramos en la carpeta docs.
3. Seleccionamos el archivo Markdown.
4. Realizamos las modificaciones necesarias.
5. Guardamos los cambios mediante un commit.
6. Comprobamos la sincronización con GitBook.

## 5. Gestión del conocimiento

Utilizaremos BookStack y Wiki.js para organizar:

- Manuales técnicos.
- Incidencias y soluciones.
- Decisiones de arquitectura.
- Procedimientos de administración.
- Actas de reuniones.

## 6. Resolución de problemas

Si los cambios no aparecen en GitBook:

- Comprobamos el estado de Git Sync.
- Revisamos el archivo SUMMARY.md.
- Verificamos la ruta de la documentación.
- Actualizamos la página del navegador.

## 7. Buenas prácticas

- Mantenemos actualizada la documentación.
- Evitamos duplicar información.
- Protegemos las credenciales.
- Utilizamos mensajes de commit descriptivos.
