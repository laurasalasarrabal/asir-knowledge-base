# ASIR Knowledge Base

## Descripción del proyecto

ASIR Knowledge Base es una plataforma de documentación
técnica y gestión del conocimiento orientada a la
administración de sistemas informáticos.

## Objetivos

- Centralizar la documentación técnica.
- Organizar manuales y procedimientos.
- Facilitar la resolución de incidencias.
- Aplicar la metodología Docs as Code.
- Disponer de una base de conocimiento reutilizable.

## Tecnologías seleccionadas

- GitHub.
- GitBook.
- Markdown.
- Mermaid.
- Rocky Linux 9.
- Docker y Docker Compose.
- BookStack.
- Wiki.js.

## Documentación técnica prevista

- Arquitectura del sistema.
- Guía de despliegue.
- Manual de usuario.
